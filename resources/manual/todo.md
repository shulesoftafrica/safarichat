## Onboarding Workflow Restructure

### Objective
Streamline the onboarding process to ensure businesses set up essential components before going live.

### Revised Flow

#### Step 1: WhatsApp Integration
- User scans QR code and enables WhatsApp integration
- **Action**: Redirect to Product/Service Setup (not home page)

#### Step 2: Product/Service Configuration (Required)
- Display clear message: "Before you can start selling, you need to define at least one product or service"
- User adds minimum one product/service with:
    - Product/service name
    - Description
    - Pricing
- **Validation**: User cannot proceed without completing this step

#### Step 3: AI Sales Agent Configuration
- Guide user through AI agent setup:
    - Business tone and personality
    - Response templates
    - Automation rules
- **On Success**: Display confirmation message:
    - "🎉 Your system is ready to start selling!"
    - Show summary of configured settings

#### Step 4: Choose Your Next Step
Present two clear options:

**Option A: Proactive Outreach**
- Upload existing contacts
- Start immediate conversations
- Button: "Import Contacts"

**Option B: Inbound Sales**
- Wait for customers to initiate contact
- Promote WhatsApp number on social media
- Button: "View My WhatsApp Number"

### Success Criteria
- All essential setup completed before live operations
- Clear guidance at each step
- Flexible go-to-market approach based on business needs
